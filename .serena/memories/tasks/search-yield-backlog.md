## Источники (осталось)

1. **Remotive: публичный API отдаёт 18 вакансий.** Параметры `category`/`limit`
   игнорируются. Выяснить, есть ли лента полнее; если нет — назвать площадку
   исчерпанной в README.
2. **RemoteOK: 96 из 99 за подпиской.** `can_apply` пускает только
   `original: true`: 3 из 99 сегодня, 2 из 100 три недели назад, пересечение с
   нашими словами — ноль. Решить, держим ли площадку.
3. **RemoteOK глушит исключения** — `except Exception: return []`. Сбой сети
   неотличим от «вакансий нет».
4. **Wellfound молча даёт ноль** без своего Chrome. Предупреждать при старте.
7. **hh: потолок `MATCH_SCAN_LIMIT=150`** упёрся: оценили 150, набрали 29.
   Решение владельца — прямые деньги.
8. **hh: галка `label=low_performance`** («меньше 10 откликов») снята живьём.
9. **Новые источники** — только после замера воронки.

## Оценка релевантности

10. **`temperature` не задана, работает 1.0 — оценка недетерминирована.** Одна
    вакансия за семь прогонов: 28, 38, 38, 38, 62, 74, 78 при пороге 60. На
    чужих вакансиях разброс 6–7, на подходящих — до 50. С `temperature=0`
    схлопывается. Одна строка, меняет отбор на ВСЕХ площадках — РЕШЕНИЕ
    ВЛАДЕЛЬЦА, ждёт слова.
11. **Локация не доходит до модели** (в скоринг идут только title и description).
12. **Модель судит вопреки профилю**: «требуется 3+ года» считает
    дисквалифицирующим, снижает балл за неудалённый формат вопреки прямому
    запрету в `search_profile.txt`.
13. **`title_matches` не ловит «Software Engineering Intern»** — решено НЕ
    чинить: расширение впустит 11 мусорных ради одной хорошей.
